AEVUM STUDENT MANAGEMENT SYSTEM

Capstone Project Report

Prepared for final-year/capstone evaluation

Abstract

Aevum is a premium student management and productivity platform developed using Django, SQLite, Bootstrap 5, JavaScript, and Django REST Framework. The system centralizes academic notes, tasks, events, code snippets, focus tracking, and public portfolio sharing in one web application. Aevum was designed especially for practical use by students who may rely on browser-based development environments such as GitHub Codespaces. The platform supports secure authentication, public share links, code-file upload, and direct code publishing to GitHub using repository credentials configured by the user. The system also exposes REST API endpoints to support future integration with mobile applications or React front ends.

Chapter 1 – Introduction

Students often use multiple disconnected tools for note taking, code storage, scheduling, and assignment management. This creates fragmentation, duplication of effort, and difficulty presenting work to teachers or external evaluators. Aevum solves this problem by unifying academic and technical workflows in a single premium web application.

Chapter 2 – Requirements Analysis

Functional Requirements

  • User registration, login, logout, and admin access
  • Profile management with GitHub configuration
  • Create, update, view, and delete notes
  • Tagging, pinning, and file attachments for notes
  • Kanban-based task management
  • Event scheduling
  • Code snippet management and source-file upload
  • Direct upload of code snippets to GitHub
  • Focus session logging
  • Search and public sharing
  • REST API access for core resources

Non-Functional Requirements

  • Responsive UI suitable for phone users
  • Simple SQLite setup
  • Maintainable Django architecture
  • Secure per-user data isolation
  • Deployment-friendly design using WhiteNoise

Chapter 3 – System Design

Architecture

Aevum follows a standard three-layer web architecture:

  • Presentation layer: Django templates, Bootstrap 5, JavaScript
  • Application layer: Django views, forms, business logic, GitHub integration
  • Data layer: SQLite models for users, notes, tasks, events, snippets, and shares

ER Diagram Description

The central entity is the Django User model. Each User has one Profile. A User can create many Tags, Notes, Tasks, Events, CodeSnippets, FocusSessions, and SharedLinks. Notes have a many-to-many relationship with Tags. SharedLinks can reference either a Note, a CodeSnippet, or a public Profile page.

Chapter 4 – Implementation

The system was implemented as a Django project named Aevum with two main apps: hub and api. The hub app contains the main business logic, forms, views, templates, and GitHub upload helper. The api app contains serializers and REST API viewsets.

Premium UI

The UI uses dark glassmorphism, gradients, frosted panels, responsive layouts, Chart.js analytics, and a portfolio-style public page inspired by premium portfolio designs.

Chapter 6 – Conclusion

Aevum successfully demonstrates a capstone-level student management and productivity solution with both academic and developer-oriented features. The system is practical, visually polished, and deployment-ready for browser-based workflows. Its direct GitHub upload capability, public sharing support, and REST API make it stand out from basic CRUD-based student projects.

Future Scope
